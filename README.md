# JavaScript Projects
My repository of projects made for the JavaScript Course from The Tech Academy.

## Project List
### Calculator
[This project](https://github.com/nmartin2600/JAVASCRIPT-PROJECTS/commit/a41b1cad7503d590fe239374c5d3ef6a629a61bc) is a web version of a basic 4 function calculator. It supports operations for addition, subtraction, multiplication, and division. 
### Pizza Menu
[This project](https://github.com/nmartin2600/JAVASCRIPT-PROJECTS/tree/main/Pizza_Project) is a web menu for ordering pizza with a various selection of sizes and toppings. It takes the input information from the selections for the order and calculates the total price.
### Tic-Tac-Toe Game
[This project](https://github.com/nmartin2600/JAVASCRIPT-PROJECTS/tree/main/TicTacToe) is a mock web version of the classic Tic-Tac-Toe game. It randomly selects which of the two players goes first, then allows them to select a square on the grid display to mark the spot they want.
### To-do App
[This project](https://github.com/nmartin2600/JAVASCRIPT-PROJECTS/tree/main/todo_app) is a web to-do list app where users can enter a task into a text box, then have it displayed in a list on the page. Each individual task can be removed from the list and the list will reformat itself upon each addition or removal.
